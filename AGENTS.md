# Medrelay - AI Healthcare Automation

This project contains the landing page and web application for Medrelay, an AI-powered automation platform for hospitals, clinics, and healthcare providers.

## Project Overview

Medrelay automates repetitive administrative tasks in healthcare settings, including:
- Patient WhatsApp conversations
- Appointment booking and management
- Follow-ups and reminders
- Patient information management
- AI voice calls
- Workflow automation

## Development Guidelines

When working on this project:
- Maintain the professional, premium healthcare aesthetic
- Ensure all changes are production-ready
- Test responsive design across all devices
- Follow the established component patterns
- Keep the focus on clarity and trustworthiness
