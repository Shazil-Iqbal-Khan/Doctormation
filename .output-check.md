# Render Deployment Debugging Guide

## Common 404 Errors on Render

### 1. Check Your Render Deployment URL
The URL should be something like: `https://doctormation.onrender.com`

### 2. Open Browser DevTools (F12) and check:
- **Console tab**: Look for the exact 404 error
- **Network tab**: See which file is failing (CSS, JS, favicon, etc.)

### 3. Most Common Issues:

#### Issue A: Favicon 404 (Safe to Ignore)
```
Failed to load resource: /favicon.ico 404
```
**Solution:** This is just the browser looking for a favicon. Won't affect functionality.

#### Issue B: Assets 404 (Critical)
```
Failed to load resource: /assets/styles-xxx.css 404
Failed to load resource: /assets/index-xxx.js 404
```
**Solution:** Assets not being served correctly.

#### Issue C: Root path 404
```
Failed to load resource: / 404
```
**Solution:** Server not handling root route.

## How to Fix on Render:

### Step 1: Check Render Logs
1. Go to your Render dashboard
2. Click on your "doctormation" service
3. Click "Logs" tab
4. Look for:
   - ✅ `➜ Listening on: http://0.0.0.0:XXXX/`
   - ❌ Any error messages

### Step 2: Verify Build Completed
In Render logs, you should see:
```
==> Build successful 🎉
==> Deploying...
Starting server...
PORT: 10000
HOST: 0.0.0.0
➜ Listening on: http://0.0.0.0:10000/
```

### Step 3: Test the URL
Try these URLs in your browser:
1. `https://your-app.onrender.com/` - Should load the site
2. `https://your-app.onrender.com/assets/styles-CrWfpTDB.css` - Should return CSS
3. `https://your-app.onrender.com/favicon.ico` - Should return favicon

### Step 4: If Still Getting 404

**Clear Build Cache:**
1. In Render dashboard → your service
2. Click "Manual Deploy"
3. Select "Clear build cache & deploy"
4. Wait for rebuild (5-10 minutes)

**Check Environment:**
- Ensure Node version is 20.11.0
- Ensure start command is: `node server-start.mjs`
- Ensure build command is: `npm ci && npm run build`

### Step 5: Check for Port Issues
Render assigns a random PORT. Our `server-start.mjs` handles this.

Verify in logs:
```
PORT: 10000  <-- Should be present
HOST: 0.0.0.0  <-- Should be 0.0.0.0, not localhost
```
